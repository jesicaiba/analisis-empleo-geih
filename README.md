# Análisis de Empleo y Ocupación - GEIH (DANE)

## 📌 Descripción del Proyecto
Este proyecto realiza un análisis estadístico y procesamiento de datos simulados basados en la estructura de los microdatos de la **Gran Encuesta Integrada de Hogares (GEIH) del DANE**. Permite evaluar la distribución de la población activa por rangos de edad y su condición de ocupación (OCI).

## 🛠️ Tecnologías Utilizadas
- **Python 3**
- **Pandas & NumPy** (Procesamiento y análisis de datos)
- **Matplotlib** (Visualización de resultados)
- **Git / GitHub** (Control de versiones)
